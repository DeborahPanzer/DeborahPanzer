### 💳 Open-Source Payment Infrastructure Suite
I develop and maintain modular, zero-dependency abstractions designed to mitigate dispute risks, eliminate double-charging, and orchestrate complex settlement lifecycles:

* 💸 **[Payout-](https://github.com/DeborahPanzer/Payout-)** — Automated disbursement & payout engine featuring distributed retry queues, idempotency keys, and scheduled batch settlements.
* 🛍️ **[Checkout-](https://github.com/DeborahPanzer/Checkout-)** — Lightweight checkout session coordinator built for dynamic currency routing, zero-friction client sessions, and low-latency failover.
* 🔄 **[Refund-](https://github.com/DeborahPanzer/Refund-)** — High-reliability refund middleware with dispute mitigation logic, audit logging, and automated state synchronization.
